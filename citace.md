# Citace a zdroje

## Zadání a reference

- Harvard University, CS50's Web Programming with Python and JavaScript, Project 0: Search. <https://cs50.harvard.edu/web/projects/0/search/>. Zadání a požadované chování stránek pro hledání, obrázky a rozšířené hledání.
- Pavel Martínek, výukové zadání „Search“. <https://martinekpavel.github.io/vyuka/web_html/09search.html>. Požadavky na doplňkovou stránku s formuláři, validátory a citace.
- W3C Markup Validation Service. <https://validator.w3.org/>.
- W3C CSS Validation Service. <https://jigsaw.w3.org/css-validator/>.

## Použité AI prompty

- Uživatelský prompt v této konverzaci: „Vytvořte na GitHubu nový repozitář `googlesearch`; otevřete (naklonujte) repozitář ve VS Code jako nový projekt; vytvořte další stránku obsahující co největší množství formulářových prvků (input, select, checkbox, radio, textarea, button, …); na všech stránkách přidejte odkazy na validaci HTML a CSS a na soubor s citacemi; přidejte odkaz na portfolio.“
- Následný prompt pro vytvoření základní vyhledávací stránky podle CS50 Project 0: Search (z předchozího uživatelského zadání v této konverzaci).

## Vlastní tvorba

HTML stránky, styly a skript pro sestavení odkazů na validátory byly vytvořeny pro tento školní projekt. Grafické prvky jsou vytvořené pomocí textu a CSS; nejsou použity externí obrázky ani knihovny.
